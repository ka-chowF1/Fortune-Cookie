# Fortune Cookie Generator

A static fortune cookie with a cracking animation and 20 mildly insulting fortunes. Click the cookie or Open my cookie, then Crack another to reset. Consecutive fortunes never repeat. Keyboard controls, screen reader announcements, and reduced motion preferences are supported.

## Preview

Run `npm start` in this folder, then visit http://localhost:8072. You can also open `dist/index.html` directly. Run `npm test` for the selection and interaction checks. No installation or build step is required.

## Publish

Create a public GitHub repository and upload this folder's contents, including `.github/workflows/deploy.yml`. In Settings → Pages, select GitHub Actions as the source, then run the deployment workflow. It tests the project and publishes `dist`.
